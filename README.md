# CRYPTO AGENT X

自律型・検証駆動の仮想通貨トレーディングエージェント。24/7でデータを収集し、市場の構造的非効率（ファンディング等）からエッジを発見・検証し、ペーパートレードで自律運用する。

> ⚠️ **ペーパートレード（仮想売買）のみ。** 実弾発注は行わない。無料の取引所公開APIのみを使用（APIキー不要）。投資助言ではない。

## 構成

- `server/` — 依存ゼロのNodeサーバ（`index.js`）。60秒毎にデータ収集＋ペーパー執行、30分毎にエッジ再スキャン、2時間毎に自律エッジ研究。`http://localhost:8790` でAPI/ダッシュボード配信。
- `web/` — ランディング／ダッシュボード（three.js製3Dコア＋自前Canvasチャート）。
- `PLAYBOOK.md` — 運用手順。
- `FUTURES_ADAPTER_DESIGN.md` — 先物（商品季節性）への横展開の設計メモ。

## 検証済みエッジ（4系統・すべて損切り/利確/手数料込ウォークフォワード検証）

1. **funding** — ファンディング百分位の極値をトレンド一致でフェード（ショート）。実弾唯一のプラス源。
2. **trend** — 順張り（銘柄別最適化、頑健な XTZ/ETH/ADA を厳選）。
3. **calendar** — 曜日シーズナリティ（木曜ショート等）。
4. **mr_rsi2** — 日足RSU2の逆張り平均回帰。

各エッジは互いに概ね無相関で、低ドローダウンの分散を狙う。

## リスク管理

- 1トレード1%リスク／1銘柄1ポジ／同時保有・同方向の上限／評価額ドローダウン12%でサーキットブレーカー。
- **エッジ自動キル**：稼働中エッジが直近で一定以上負けたら自動停止。
- **厳格オート昇格**：長期に安定合格するエッジのみ自動でトレード対象に追加。
- **週次スコアカード**：実測をエッジ別に自動集計。

## 起動

```bash
cd server && node index.js   # → http://localhost:8790
```

macOSでは launchd（`com.cryptoagentx.server`）で常駐（`caffeinate`でスリープ抑止・KeepAliveで自動復帰）。

## 注意

`server/data/`（市場ログ・検証ログ）は実行時に自動生成されるため gitignore 済み。
